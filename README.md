# Laboratorio POO

Este proyecto es un laboratorio de Programación Orientada a Objetos (POO) en Java. El objetivo es practicar los conceptos fundamentales de POO mediante la implementación de diferentes clases, modelos, servicios y vistas para varias entidades.

## Estructura del Proyecto

- **Model/**: Contiene las clases modelo que representan la lógica y atributos de las entidades principales (Cliente, Empleado, Estudiante, Persona, Producto, Vehículo).
- **services/**: Incluye las clases de servicio que gestionan la lógica de negocio y operaciones sobre los modelos.
- **View/**: Contiene las clases de vista encargadas de la interacción con el usuario.
- Archivos `*Main.java`: Clases principales para ejecutar ejemplos o pruebas de cada entidad.

## Entidades Principales
- Cliente
- Empleado
- Estudiante
- Persona
- Producto
- Vehículo

Cada entidad cuenta con su propio modelo, servicio y vista.

## Cómo ejecutar
1. Abre el proyecto en tu IDE favorito (por ejemplo, VS Code o IntelliJ IDEA).
2. Compila los archivos `.java`.
3. Ejecuta cualquiera de los archivos `*Main.java` para probar la funcionalidad de cada entidad.
